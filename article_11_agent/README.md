# article_11_agent

## Activate
```bash
source ../.venv/bin/activate
```

## Run Order
```bash
python3 main.py
```
Interactive chat with the rebuilt chatbot; type a test number (1-12) or your own message, `new` to start a new conversation, and `quit` to exit.

```bash
python3 scenarios.py
```
Runs all 19 scenarios without typing, feeds scripted replies to every clarification, and checks each against its expectations.
